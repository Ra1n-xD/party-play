# Audio assets

`laugh.wav` is derived from **Laugh_male_quiet.wav**, uploaded by
`deleted_user_2104797` to Freesound on September 30, 2012.

- Source: https://freesound.org/people/deleted_user_2104797/sounds/166141/
- License: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
- Original recording: mono, 48 kHz, approximately 2.018 seconds.
- Public preview used: https://cdn.freesound.org/previews/166/166141_2104797-hq.mp3
- Processing: volume normalization (9.5×), a 20 ms fade in and 118 ms fade out,
  saved as 16-bit PCM WAV. No pitch shifting or looping.

The recording is bundled with the application; playback makes no external requests.
