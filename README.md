# 🎉 PartyPlay

Мультиплеерная платформа для вечеринок в реальном времени. Играй с друзьями с любого устройства — просто поделись кодом комнаты.

## 🎮 Доступные игры

### 🏠 Бункер

Социальная игра на выживание для 4–16 игроков. Происходит катастрофа, и есть бункер с ограниченным количеством мест. Каждый игрок получает случайного персонажа с уникальными характеристиками — профессия, здоровье, хобби, багаж, фобия и особая карта действия. За 5 раундов игроки раскрывают свои атрибуты, спорят за место и голосуют за исключение тех, кто не заслуживает спасения. Выживи и попади в бункер!

### 🃏 Подкидной дурак

Серверная карточная игра для 2–6 участников, включая ботов. Атакуй, отбивайся, подкидывай карты подходящего достоинства и постарайся первым избавиться от руки. Доступны зрители, реконнект, временная замена ботом и таймер хода.

### 🎨 UNO

Цветовая карточная партия для 2–10 участников, включая ботов. Совмещай цвет,
число или действие, выбирай новый цвет, вовремя объявляй UNO и решай, стоит ли
оспаривать Wild Draw Four. Поддерживаются зрители, реконнект, временная замена
ботом, таймер хода и повторная партия в той же комнате.

## 🧩 Архитектура

Платформа построена как модульная система: каждая игра хранит собственные типы, серверные правила и клиентский интерфейс, а общее ядро предоставляет комнаты, лобби, сессии, сокеты и реконнект. Подробнее в [архитектурной документации](docs/ARCHITECTURE.md).

## 🛠️ Стек технологий

- **Сервер:** Node.js, Express, Socket.IO
- **Клиент:** React 18, Vite, TypeScript
- **Структура:** монорепо на npm workspaces (`shared`, `server`, `client`)
