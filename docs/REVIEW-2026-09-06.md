# Ревью приложения от 6 сентября 2026

Проверены общие потоки комнат, сессий, переподключения, управления местами,
публичного каталога и реакций; серверные правила, проекции и боты трёх активных
игр; игровые экраны, подсказки, таймеры и механизмы анимаций. Пять карточек
«Скоро» в каталоге не являются реализованными играми.

## Ручная проверка

Проверка выполнялась на локальном сервере с отдельным временным файлом
статистики, без изменения `.env` и постоянных данных. Для Бункера использовался
существующий режим коротких таймеров.

- Дурак: партия с ботом, раздача, выбор защиты для конкретной атаки,
  серверное принятие защиты, дальнейшее подкидывание, выход из комнаты.
- UNO: два клиента игроков и бот, готовность, запуск, отдельные руки,
  розыгрыш карты с клавиатуры, выход другого игрока, пауза, удаление его места,
  возобновление отсчёта, автоматический добор и следующий ход бота.
- Бункер: два клиента игроков, два бота и отдельный зритель; вход через
  открытый каталог, раскрытия, удаление профессии текущего игрока,
  продолжение после административной паузы, голосование и переголосование.
- Бункер: административное исключение до вместимости убежища, завершение,
  сохранение победителя после его выхода, очистка повторного лобби и запуск
  следующей партии.
- Бункер: выход и прямое возвращение на сохранённое место с прежним досье
  и восстановленным ходом.
- Диалоги: событие поверх правил; Escape закрывает верхнее окно, правила
  остаются открытыми и получают фокус; повторный Escape закрывает правила.
- Визуально просмотрены все три игровые экрана на ширине 390 px, карточка
  раскрытия Бункера и настольные представления дополнительных клиентов.

## Границы проверки

Проверка типов клиента и сервера, `npm run build`, `npm run format:check`
и `git diff --check` завершились успешно после изменений. Автоматические тесты
не создавались и не запускались согласно
правилам репозитория. Ручные сценарии не перебирают все расклады, размеры комнат,
браузеры, задержки сети и сочетания административных действий; отсутствие
ошибок во всех возможных состояниях не утверждается. В частности, ветки
оспаривания +4 и паузы во время анимации Дурака проверены по коду, без отдельного
полного ручного прогона каждой ветки. Стрессовая серия подключений зрителей
и все режимы сокращения анимаций также не прогонялись в браузере.

Версия приложения: **3.1.6 → 3.1.7**, patch для исправлений без изменения
публичных контрактов. Версии отдельных рабочих пакетов сохранены.

Изменение `AGENTS.md`, появившееся во время работы, не входит в эти исправления.
